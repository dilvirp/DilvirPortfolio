# Dilvir Parmar | Developer Portfolio 

A personal portfolio website I built using React, TypeScript  and CSS.

This website showscases my technical skills, software development projects, professional experience, and contact information.

## Live website 

[View My Portfolio](https://dilvir-portfolio.vercel.app/)

## Features

- Responsive design for desktop, tablet and mobile devices
- Light and dark theme toggle
- Technical skill showcase
- Software development project cards
- Professional experience section 
- Contact links for email, LinkedIn, and GitHub
- Smooth navigation between sections.
